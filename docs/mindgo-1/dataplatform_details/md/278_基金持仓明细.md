# 基金持仓明细

- ID: 278
- 分类: 基金 / 场外基金 / 基金持仓情况
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/278
- 简介: 基金半年报、年报披露的持仓明细数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 基金代码 |
| position\_symbol | 持仓代码 |
| name | 持仓名称 |
| type | 类型 |
| amount | 数量 |
| value | 市值 |
| change | 持仓变动 |
| value\_percent | 证券投资市值比 |
| net\_value\_percent | 基金资产净值比 |
| report\_date | 公告日期 |
| stat\_date | 报告截止日期 |

## 字段说明

| 字段                | 含义           | 格式     |
| ------------------- | -------------- | -------- |
| symbol              | 基金代码       | str      |
| position\_symbol    | 持仓代码       | str      |
| name                | 持仓名称       | str      |
| type                | 类型           | str      |
| amount              | 数量           | float64  |
| value               | 市值           | float64  |
| change              | 持仓变动       | float64  |
| value\_percent      | 证券投资市值比 | float64  |
| net\_value\_percent | 基金资产净值比 | float64  |
| report\_date        | 公告日期       | datetime |
| stat\_date          | 报告截止日期   | datetime |


## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全部基金持仓明细
run_query(
    query(
        position_detail
    )
)
```
