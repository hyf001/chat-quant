# 公司员工数量表

- ID: 85
- 分类: 股票 / A股 / 上市公司资料
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/85
- 简介: 记录公司在职、退休员工数量

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 同花顺代码 |
| report_date | 公布日 |
| stat_date | 实际变更日 |
| total_employees | 在职员工总数 |
| retired_employees | 退休员工数 |
| total_employees_subsidiaries | 主要子公司在职员工数 |
| total_employees_receiving | 当期领取薪酬的总员工数 |
| total_employees_parent | 母公司在职员工数 |
