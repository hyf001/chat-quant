# 行业分类信息

- ID: 24
- 分类: 股票 / A股 / 行业分类
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/24
- 简介: 同花顺一级行业分类信息

## 数据字典

| 字段 | 含义 |
| --- | --- |
| industry\_name | 行业名称 |
| available\_date | 行业可用日 |
| disabled\_date | 行业删除日 |
| industry\_index | 行业对应指数代码 |
| industry\_rank | 行业等级 |
| industry\_symbol | 行业代码 |
| industry\_thscode | 行业代码(同花顺) |
| industry\_type | 行业分类类型 |
| industry\_typecode | 行业分类类型代码 |

## 字段说明

| 字段                                 | 含义             | 其他说明           |
| ------------------------------------ | ---------------- | ------------------ |
| industry\_name                       | 行业名称         | 索引列             |
| available\_date                      | 行业可用日       |                    |
| disabled\_date                       | 行业删除日       | 如未被删除则为None |
| industry\_index                      | 行业对应指数代码 |                    |
| industry\_rank                       | 行业等级         |                    |
| industry\_symbol                     | 行业代码         |                    |
| industry\_thscode                    | 行业代码(同花顺) |                    |
| industry\_type                       | 行业分类类型     |                    |
| industry\_typecode                   | 行业分类类型代码 |                    |



## 使用代码

```python
get_industry_relate(date='now', types='industryid1', fields=None)
```

参数说明：


| 参数   | 含义         | 支持格式                    | 说明                                 |
| ------ | ------------ | --------------------------- | ------------------------------------ |
| date   | 查询日期     | str,int,float,datetime-like | 默认为当前日期                       |
| types  | 行业分类类型 | str                         | 默认取同花顺一级行业分类             |
| fields | 字段名       | list                        | 参考“字段说明”，默认取所有可取字段 |

**注：**

支持以下行业分类

* 同花顺行业分类
  * 同花顺一级 - `industryid1`
  * 同花顺一级 - `industryid2`
  * 同花顺一级 - `industryid3`
* 申万行业分类
  * 申万一级 - `s_industryid1`
  * 申万二级 - `s_industryid2`
  * 申万三级 - `s_industryid3`
* 中信行业分类
  * 中信一级 - `ci_industryid1`
  * 中信二级 - `ci_industryid2`
  * 中信三级 - `ci_industryid3`
* 证监会行业分类 - `c_industryid`

使用样例

```python
#获取2023年2月1日的同花顺一级行业分类信息
get_industry_relate('2023-02-01', types='industryid1')
```
