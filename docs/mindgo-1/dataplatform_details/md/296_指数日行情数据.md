# 指数日行情数据

- ID: 296
- 分类: 指数 / 指数行情数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/296
- 简介: 常用指数日频行情数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| factor | 复权因子 |
| volume | 成交量 |
| turnover | 成交金额(元) |
| turnover_rate | 换手率(%) |
| is_paused | 是否停牌 |
| high_limit | 涨停价(元) |
| low_limit | 跌停价(元) |
| avg_price | 均价(元) |
| prev_close | 前收盘价(元) |
| quote_rate | 涨跌幅(%) |
| amp_rate | 振幅(%) |
| is_st | 是否st |

## 字段说明

| 字段          | 含义         | 格式    | 其他说明                           |
| ------------- | ------------ | ------- | ---------------------------------- |
| open          | 开盘价       | float64 |                                    |
| high          | 最高价       | float64 |                                    |
| low           | 最低价       | float64 |                                    |
| close         | 收盘价       | float64 |                                    |
| factor        | 复权因子     | float64 | 复权因子 = 后复权价格 / 不复权价格 |
| volume        | 成交量       | float64 |                                    |
| turnover      | 成交金额(元) | float64 |                                    |
| turnover_rate | 换手率(%)    | float64 |                                    |
| is_paused     | 是否停牌     | float64 | 返回值为0或1, 0表示未停牌          |
| high_limit    | 涨停价(元)   | float64 |                                    |
| low_limit     | 跌停价(元)   | float64 |                                    |
| avg_price     | 均价(元)     | float64 | 成交额/成交量                      |
| prev_close    | 前收盘价(元) | float64 |                                    |
| quote_rate    | 涨跌幅(%)    | float64 |                                    |
| amp_rate      | 振幅(%)      | float64 | 振幅=(最高价－最低价)/昨收盘价     |
| is_st         | 是否st       | float64 | 返回值为0或1, 0表示非ST            |


## 使用代码

```python
get_price(
    securities,
    start_date=None,
    end_date='20180101',
    fre_step='1d',
    fields=None,
    skip_paused=False,
    fq='pre',
    bar_count=0,
    is_panel=False,
)
```

参数说明：

| 参数        | 含义             | 支持格式                    | 说明                                                                         |
| ----------- | ---------------- | --------------------------- | ---------------------------------------------------------------------------- |
| securities  | 标的代码         | str,list                    |                                                                              |
| start_date  | 起始日期         | str,int,float,datetime-like |                                                                              |
| end_date    | 结束日期         | str,int,float,datetime-like |                                                                              |
| fre_step    | 时间步长         | str                         | 取日频行情时 `fre_step='1d'`                                               |
| fields      | 数据字段         | list                        | 支持字段可参考“字段说明”                                                   |
| skip_paused | 是否跳过停牌数据 | bool                        | `True`:表示跳过 <br />`False`:表示不跳过                                 |
| fq          | 复权选项         | str                         | `fq=None`: 不复权 <br /> `fq='post'`: 后复权 <br /> `fq='pre'`: 前复权 |
| bar_count   | 历史长度         | int                         | `bar_count`不为0时 `start_date`必须为 `None`，否则会报错               |
| is_panel    | 返回数据格式     | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据   |

使用样例

```python
[IN]:
# 获取中证500指数、沪深300指数2023年4月6日前3天的数据
value = get_price(
    securities=['000905.SH', '000300.SH'],
    start_date=None,
    end_date='20230406',
    fre_step='1d',
    fields=['open','high','low','close','volume'],
    skip_paused=False,
    fq='pre',
    bar_count=3,
    is_panel=1,
)
# 打印收盘价数据
print(value['close']) 
```
