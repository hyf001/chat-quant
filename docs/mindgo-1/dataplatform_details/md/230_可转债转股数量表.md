# 可转债转股数量表

- ID: 230
- 分类: 债券 / 可转债 / 可转债条款信息
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/230
- 简介: 记录可转债转股数量、户数、价格数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 可转债代码 |
| report\_date | 报告日 |
| end\_date | 截止日 |
| convert\_stocks\_cum | 累计转股数量 |
| convert\_stocks\_current | 当期转股数量 |
| convert\_holder\_current | 当期转股户数 |
| convert\_bondvalue\_current | 当期转股面值 |
| convert\_bondvalue\_cum | 累计转股面值 |
| convert\_ratio\_cum | 累计转股比例 |
| convert\_price\_current | 当期转股价格 |
