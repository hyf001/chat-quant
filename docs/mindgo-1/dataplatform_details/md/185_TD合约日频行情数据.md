# TD合约日频行情数据

- ID: 185
- 分类: 期货 / 延期交收合约(T+D合约) / TD合约行情数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/185
- 简介: T+D合约日频行情数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| volume | 成交量 |
| turnover | 成交金额(元) |
| weighted_avg_price | 加权平均价(元) |

## 字段说明

| 字段               | 含义           | 格式    |
| ------------------ | -------------- | ------- |
| open               | 开盘价         | float64 |
| high               | 最高价         | float64 |
| low                | 最低价         | float64 |
| close              | 收盘价         | float64 |
| volume             | 成交量         | float64 |
| turnover           | 成交金额(元)   | float64 |
| weighted_avg_price | 加权平均价(元) | float64 |


## 使用代码

```python
get_price_td(
    inst_id_list,
    start_date=None,
    end_date=None,
    fre_step='1d',
    fields=None,
    bar_count=None,
    is_panel=0,
)
```

参数说明：


| 参数         | 含义         | 支持格式                    | 说明                                                               |
| ------------ | ------------ | --------------------------- | ------------------------------------------------------------------ |
| inst_id_list | 标的类型     | str,list                    |                                                                    |
| start_date   | 起始日期     | str,int,float,datetime-like |                                                                    |
| end_date     | 结束日期     | str,int,float,datetime-like |                                                                    |
| fre_step     | 时间步长     | str                         | 取日频行情时`fre_step='1d'`                                        |
| fields       | 数据字段     | list                        | 支持字段可参考“字段说明”                                         |
| bar_count    | 历史长度     | int                         | `bar_count`不为0时，`start_date`必须为 `None`，否则会报错          |
| is_panel     | 返回数据格式 | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据 |

使用样例

```python
[IN]:
# 获取AUTD、AGTD两个标的在2023年4月6日前3天的数据
value = get_price_td(
    inst_id_list = ['AUTD','AGTD'],
    start_date=None,
    end_date='20230410',
    fre_step='1d',
    fields=['open','high','low','close'],
    bar_count=3,
    is_panel=1,
)
# 打印收盘价数据
print(value['close']) 
```

```python
[OUT]:
              AUTD    AGTD
2023-04-06  446.51  5538.0
2023-04-07  445.77  5575.0
2023-04-10  442.04  5500.0
```
