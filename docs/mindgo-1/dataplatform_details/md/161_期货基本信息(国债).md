# 期货基本信息(国债)

- ID: 161
- 分类: 期货 / 内地期货 / 期货基本信息
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/161
- 简介: 国债期货基本信息，包含合约代码、中文简称、上市日期、退市日期等数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 标的代码 |
| display_name | 中文简称 |
| name | 拼音简称 |
| start_date | 上市日期 |
| end_date | 退市日期 |
| type | 种类 |
| exchange | 交易所 |

## 字段说明

| 字段         | 含义     | 其他说明               |
| ------------ | -------- | ---------------------- |
| symbol       | 标的代码 | 索引列                 |
| display_name | 中文简称 |                        |
| name         | 拼音简称 |                        |
| start_date   | 上市日期 |                        |
| end_date     | 退市日期 | 如未退市则为2200-01-01 |
| type         | 种类     |                        |
| exchange     | 交易所   |                        |


## 使用代码

```python
get_all_securities(ty=None,date=None)
```

参数说明：


| 参数 | 含义     | 支持格式                    | 说明                                                                                                                 |
| ---- | -------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| ty   | 标的类型 | str                         | 查询国债期货信息时，ty='bond_futures'                                                                                |
| date | 查询日期 | str,int,float,datetime-like | 1.在回测环境:默认值会随着回测日期变化而变化,的上一个交易日<br />2.在研究环境和模拟交易环境: 默认是今天的上一个交易日 |

使用样例

```python
#获取2023年2月1日处于上市状态的所有国债期货的基本信息
get_all_securities('bond_futures','2023-02-01')
```

```python
#获取当前处于上市状态的所有国债期货的基本信息
get_all_securities('bond_futures','now')
```
