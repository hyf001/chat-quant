# 指数分钟行情数据

- ID: 297
- 分类: 指数 / 指数行情数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/297
- 简介: 常用指数分钟频行情数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| factor | 复权因子 |
| volume | 成交量 |
| turnover | 成交金额(元) |
| turnover_rate | 换手率(%) |
| is_paused | 是否停牌 |

## 字段说明

| 字段          | 含义         | 格式    | 其他说明                           |
| ------------- | ------------ | ------- | ---------------------------------- |
| open          | 开盘价       | float64 |                                    |
| high          | 最高价       | float64 |                                    |
| low           | 最低价       | float64 |                                    |
| close         | 收盘价       | float64 |                                    |
| factor        | 复权因子     | float64 | 复权因子 = 后复权价格 / 不复权价格 |
| volume        | 成交量       | float64 |                                    |
| turnover      | 成交金额(元) | float64 |                                    |
| turnover_rate | 换手率(%)    | float64 |                                    |
| is_paused     | 是否停牌     | float64 | 返回值为0或1, 0表示未停牌          |


## 使用代码

```python
get_price(
    securities,
    start_date=None,
    end_date='20180101',
    fre_step='1d',
    fields=None,
    skip_paused=False,
    fq='pre',
    bar_count=0,
    is_panel=False,
)
```

参数说明：


| 参数        | 含义             | 支持格式                    | 说明                                                                   |
| ----------- | ---------------- | --------------------------- | ---------------------------------------------------------------------- |
| securities  | 标的代码         | str,list                    |                                                                        |
| start_date  | 起始日期         | str,int,float,datetime-like |                                                                        |
| end_date    | 结束日期         | str,int,float,datetime-like |                                                                        |
| fre_step    | 时间步长         | str                         | 取1分钟行情时`fre_step='1m'`                                           |
| fields      | 数据字段         | list                        | 支持字段可参考“字段说明”                                             |
| skip_paused | 是否跳过停牌数据 | bool                        | `True`:表示跳过 <br />`False`:表示不跳过                               |
| fq          | 复权选项         | str                         | `fq=None`: 不复权 <br /> `fq='post'`: 后复权 <br /> `fq='pre'`: 前复权 |
| bar_count   | 历史长度         | int                         | `bar_count`不为0时`start_date`必须为 `None`，否则会报错                |
| is_panel    | 返回数据格式     | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据     |

使用样例

```python
[IN]:
# 获取中证500指数、沪深300指数2023年4月6日10点30分前3分钟的数据
value = get_price(
    securities=['000905.SH', '000300.SH'],
    start_date=None,
    end_date='20230406 10:30',
    fre_step='1m',
    fields=['open','high','low','close','volume'],
    skip_paused=False,
    fq='pre',
    bar_count=3,
    is_panel=1,
)
# 打印收盘价数据
print(value['close']) 
```

## 数据样例

- 当 `securities`传入字符串时，返回 `pandas.Dataframe`对象，，行索引是 `datetime.datetime`对象，列索引是字段名称。

| ------------------- | ----- | ----- | ----- | ----- | -------- |
| 2023-02-01 10:54:00 | 14.62 | 14.62 | 14.59 | 14.60 | 773700.0 |
| 2023-02-01 10:55:00 | 14.60 | 14.60 | 14.59 | 14.59 | 370400.0 |
| 2023-02-01 10:56:00 | 14.59 | 14.59 | 14.57 | 14.57 | 856715.0 |

- 当 `securities`传入列表时，且 `is_panel`=0时，返回 `dict`对象，其 `key`是 `symbol`即证券代码, 值是 `pandas.Dataframe`，行索引是 `datetime.datetime`对象，列索引是字段名称。
