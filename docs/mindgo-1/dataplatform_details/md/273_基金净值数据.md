# 基金净值数据

- ID: 273
- 分类: 基金 / 场外基金 / 基金净值数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/273
- 简介: 场外基金净值数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| unit_net_value | 单位净值(元/份) |
| acc_net_value | 累计净值(元/份) |
| pre_net_value | 复权净值(元/份) |

## 字段说明

| 字段           | 含义            | 格式    |
| -------------- | --------------- | ------- |
| unit_net_value | 单位净值(元/份) | float64 |
| acc_net_value  | 累计净值(元/份) | float64 |
| pre_net_value  | 复权净值(元/份) | float64 |


## 使用代码

```python
get_extras(  
    security_list,
    start_date=None,
    end_date='20180101',
    fields=None,
    count=None,
    is_panel=False,
)
```

参数说明：

| 参数          | 含义         | 支持格式                    | 说明                                                                       |
| ------------- | ------------ | --------------------------- | -------------------------------------------------------------------------- |
| security_list | 标的代码     | str,list                    |                                                                            |
| start_date    | 起始日期     | str,int,float,datetime-like |                                                                            |
| end_date      | 结束日期     | str,int,float,datetime-like |                                                                            |
| fields        | 数据字段     | list                        | 支持字段可参考“字段说明”                                                 |
| is_panel      | 返回数据格式 | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据 |

使用样例

```python
[IN]:
# 获取中欧医疗健康混合A、诺安成长混合两只基金2023年4月3日至2023年4月6日的净值数据
get_extras(['003095.OF', '320007.OF'], '20230403', '20230406', ['unit_net_value','acc_net_value','pre_net_value'])

```

## 数据样例

- 当`is_panel`=0时，返回 `dict`对象，其 `key`是 `symbol`即证券代码, 值是 `pandas.Dataframe`，行索引是 `datetime.datetime`对象，列索引是字段名称。

```python

 2023-04-06           1.567          2.012       2.347070}
```

- 当 `is_panel=1`时，返回`Panel`对象, `key`为传入的`fileds`参数。`Panel`为`pandas.DataFrame`的三维结构, 选定字段后输出的便是`pandas.DataFrame`对象。
