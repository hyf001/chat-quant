**表名：asharedebt**

|含义|字段|公式|
|---------------------------------------|---------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|日期|date|-|
|公告日期|report\_date|-|
|报告期|stat\_date|-|
|股票代码|symbol|-|
|流动比率MRQ|current\_ratio\_mrq|定义：流动比率，也称营运资本比率，即公司流动资产与流动负债的比率。一般说来，比率越高，说明企业资产的变现能力越强，短期偿债能力亦越强；反之则弱。一般认为流动比率应在2：1以上，流动比率2：1，表示流动资产是流动负债的两倍，即使流动资产有一半在短期内不能变现，也能保证全部的流动负债得到偿还公式：流动比率MRQ=最近报告期流动资产合计/最近报告期流动负债合计=（货币资金+交易性金融资产+应收账款及票据+存货)/流动负债|
|速动比率MRQ|quick\_ratio\_mrq|定义：速动比率,又称“酸性测验比率”,是指速动资产对流动负债的比率它是衡量企业流动资产中可以立即变现用于偿还流动负债的能力公式：速动比率MRQ=(最近报告期流动资产-存货-预付款项-一年内到期的非流动资产-其他流动资产)/最近报告期流动负债|
|保守速动比率MRQ|conservative\_quick\_ratio\_ttm|定义：保守速动比率又称超速动比率,即用企业的超速动资产(货币资金、交易性金融资产、应收款项等)来反映和衡量企业变现能力的强弱,评价企业短期偿债能力的大小公式：保守速动比率MRQ＝(最近报告期货币资金＋交易性金融资产＋应收票据＋应收账款＋其他应收款)／最近报告期流动负债|
|现金比率MRQ|cash\_ratio\_mrq|定义：现金比率，即公司现金及现金等价物总和与流动负债的比率。衡量公司资产的流动性公式：现金比率MRQ=(最近报告期货币资金+交易性金融资产)/最近报告期流动负债|
|产权比率MRQ|equity\_ratio\_mrq|定义：产权比率是指负债合计与归属母公司的股东权益的比率,是为评估资金结构合理性的一种指标公式：产权比率MRQ＝最近报告期负债合计／归属于母公司的股东权益|
|归属母公司股东的权益／负债合计MRQ|equity\_atsopc\_to\_liab\_mrq|定义：归属母公司股东的权益／负债合计公式：最近报告期归属母公司股东的权益／负债合计|
|归属母公司股东的权益／带息债务MRQ|equity\_atsopc\_to\_dwi\_mrq|定义：归属母公司股东的权益／带息债务公式：最近报告期归属母公司股东的权益／带息债务|
|有形资产／负债合计MRQ|ta\_to\_total\_debt\_mrq|定义：有形资产／负债合计公式：最近报告期有形资产／负债合计|
|有形资产／带息债务MRQ|ta\_to\_debt\_with\_interest\_mrq|定义：有形资产／带息债务公式：最近报告期有形资产／带息债务|
|有形资产／净债务MRQ|ta\_to\_net\_debt\_mrq|定义：有形资产／净债务公式：最近报告期有形资产／净债务|
|息税折旧摊销前利润／负债合计MRQ|ebitda\_to\_total\_liab\_mrq|定义：息税折旧摊销前利润／负债合计公式：最近报告期息税折旧摊销前利润／负债合计|
|经营活动产生的现金流量净额／带息债务MRQ|ncf\_of\_oa\_to\_dwi\_mrq|定义：经营活动产生的现金流量净额／带息债务公式：最近报告期经营活动产生的现金流量净额／带息债务|
|经营活动产生的现金流量净额／净债务MRQ|ncf\_of\_oa\_to\_net\_debt\_mrq|定义：经营活动产生的现金流量净额／净债务公式：最近报告期经营活动产生的现金流量净额／净债务|
|长期债务与营运资金比率MRQ|lt\_debt\_and\_oc\_ratio\_mrq|定义：长期债务与营运资金比率公式：最近报告期长期债务与营运资金比率|
|净债务／总市值MRQ|net\_debt\_to\_equity\_value\_mrq|定义：净债务／总市值公式：最近报告期净债务／总市值|

## 使用代码

- 调用接口

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

- 参数说明：


| 参数          | 含义                         | 支持格式                    | 说明                                                                                                                                                           |
| ------------- | ---------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query\_object | 所需要查询的表条件           | query\_object               |                                                                                                                                                                |
| date          | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日<br />3.该参数与 `statDate`参数不能并存                   |
| statDate      | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同<br />3.该参数与 `date`不能并存 |
| latest        | 是否提取最新报告             | bool                        | 默认为`False`,提取原始报告数据(较早日期)                                                                                                                       |

- 使用样例

```python
#获取全市场2023年2月1日全市场股票最近一期现金比率
get_fundamentals(
    query(
        asharedebt.symbol,
        asharedebt.report_date,
        asharedebt.stat_date,
        asharedebt.cash_ratio_mrq
    ),
    date = '20230201'
)
```
