- ID: 93
- 分类: 股票 / A股 / 上市公司资料

| 字段 | 含义 |

| report\_date | 公布日 |

| shareholder\_rank | 股东名次 |
| shareholder\_name | 股东名称 |
| shareholder\_id | 股东ID |
| shareholder\_type | 股东类别 |
| holding\_num | 持有数量 |

| pledge\_num | 质押数量 |
| action\_mark | 一致行动人标志 |
