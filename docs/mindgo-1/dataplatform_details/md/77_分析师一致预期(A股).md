## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 股票代码 |
| trade\_date | 查询日期 |
| income\_forecast\_basic\_eps\_1 | 预测每股收益（本年度） |
| income\_forecast\_basic\_eps\_2 | 预测每股收益（次年） |
| income\_forecast\_net\_profit\_1 | 预测净利润（本年度） |
| income\_forecast\_net\_profit\_2 | 预测净利润（次年） |
| income\_forecast\_operating\_income\_1 | 预测营业收入（本年度） |
| income\_forecast\_operating\_income\_2 | 预测营业收入（次年） |
| valuation\_forecast\_pe\_1 | 预测市盈率（本年度） |
| valuation\_forecast\_pe\_2 | 预测市盈率（次年） |
| rating\_agency\_count\_6m | 六个月内评级机构家数 |
| composite\_rating\_6m | 六个月内综合评级（数值） |

## 字段说明

| 字段                                   | 含义                     | 说明                                                                                                       |
| -------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| symbol                                 | 股票代码                 |                                                                                                            |
| trade\_date                            | 查询日期                 |                                                                                                            |
| income\_forecast\_basic\_eps\_1        | 预测每股收益（本年度）   | 最近一个月内分析师预测当年每股收益的平均值                                                                 |
| income\_forecast\_basic\_eps\_2        | 预测每股收益（次年）     | 最近一个月内分析师预测次年每股收益的平均值                                                                 |
| income\_forecast\_net\_profit\_1       | 预测净利润（本年度）     | 最近一个月内分析师预测当年净利润的平均值                                                                   |
| income\_forecast\_net\_profit\_2       | 预测净利润（次年）       | 最近一个月内分析师预测次年净利润的平均值                                                                   |
| income\_forecast\_operating\_income\_1 | 预测营业收入（本年度）   | 最近一个月内分析师预测当年营业收入的平均值                                                                 |
| income\_forecast\_operating\_income\_2 | 预测营业收入（次年）     | 最近一个月内分析师预测次年营业收入的平均值                                                                 |
| valuation\_forecast\_pe\_1             | 预测市盈率（本年度）     | 股票在指定交易日期的收盘价*股票在指定交易日期的股本/股票在指定交易日前六个月内分析师预测当年净利润的平均值 |
| valuation\_forecast\_pe\_2             | 预测市盈率（次年）       | 股票在指定交易日期的收盘价*股票在指定交易日期的股本/股票在指定交易日前六个月内分析师预测次年净利润的平均值 |
| rating\_agency\_count\_6m              | 六个月内评级机构家数     | 六个月内评级机构总家数                                                                                     |
| composite\_rating\_6m                  | 六个月内综合评级（数值） | 六个月内综合评级平均值（数值）                                                                             |


## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取2023年2月1日的全市场股票分析师一致预期指标
run_query(
    query(
        analyst_forecast
    ).filter(
        analyst_forecast.trade_date == '20230201'
    )
)
```
