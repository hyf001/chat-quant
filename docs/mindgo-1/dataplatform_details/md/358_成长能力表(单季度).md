# 成长能力表(单季度)

- ID: 358
- 分类: 股票 / A股 / 上市公司财务数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/358
- 简介: A股上市公司单季度成长能力计算财务指标数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| overall_income_growth_ratio | 营业总收入(同比增长率) |
| opt_income_growth_ratio | 营业收入(同比增长率) |
| opt_profit_growth_ratio | 营业利润(同比增长率) |
| net_profit_growth_ratio | 净利润(同比增长率) |
| np_atsopc_yoy | 归属母公司股东的净利润(同比增长率) |

## 字段说明

**表名：growth_sq**

| 含义                               | 字段                        |
| ---------------------------------- | --------------------------- |
| 营业总收入(同比增长率)             | overall_income_growth_ratio |
| 营业收入(同比增长率)               | opt_income_growth_ratio     |
| 营业利润(同比增长率)               | opt_profit_growth_ratio     |
| 净利润(同比增长率)                 | net_profit_growth_ratio     |
| 归属母公司股东的净利润(同比增长率) | np_atsopc_yoy               |



## 使用代码

* 调用接口

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

* 参数说明：


| 参数          | 含义                         | 支持格式                    | 说明                                                                                                                                                           |
| ------------- | ---------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query\_object | 所需要查询的表条件           | query\_object               |                                                                                                                                                                |
| date          | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日<br />3.该参数与 `statDate`参数不能并存                   |
| statDate      | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同<br />3.该参数与 `date`不能并存 |
| latest        | 是否提取最新报告             | bool                        | 默认为`False`,提取原始报告数据(较早日期)                                                                                                                       |

* 使用样例

```python
#获取全市场2023年2月1日全市场股票最近一期净利润增长率(单季度同比)
get_fundamentals(
    query(
        growth_sq.symbol,
        growth_sq.report_date,
        growth_sq.stat_date,
        growth_sq.net_profit_growth_ratio
    ),
    date = '20230201'
)
```
