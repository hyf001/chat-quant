## 使用代码

* 调用接口

```python
get_dragon_tiger_league_table(query_object)
```

* 参数说明：

| 参数          | 含义               | 支持格式      | 说明 |
| ------------- | ------------------ | ------------- | ---- |
| query\_object | 所需要查询的表条件 | query\_object |      |

* 使用样例

```python
#获取2025年4月25日龙虎榜细节数据
get_dragon_tiger_league_table(
    query(
        dragon_tiger_league_table_detail.symbol,
        dragon_tiger_league_table_detail.list_date,
        dragon_tiger_league_table_detail.trading_direction,
        dragon_tiger_league_table_detail.type,
        dragon_tiger_league_table_detail.name,
        dragon_tiger_league_table_detail.list_reasons
    ).filter(dragon_tiger_league_table_detail.list_date=='2025-04-25').order_by(dragon_tiger_league_table_detail.symbol.desc())
)
```
