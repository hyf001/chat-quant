```python
run_query(query_object)
```

参数说明：

| 参数         | 含义      | 说明 |
| ------------ | --------- | ---- |
| query_object | query对象 |      |

使用样例

```python
#获取2023年2月1日全市场股票的因子数据

    query(
        factor
    ).filter(
        factor.date == '2023-02-01'
    )
)
```
