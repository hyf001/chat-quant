# 概念股数据(A股)

- ID: 70
- 分类: 股票 / A股 / 同花顺概念(A股)
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/70
- 简介: A股概念股数据，可跟据概念代码查询相关概念股

## 使用代码

```python
get_concept_stocks(symbol, date=None)
```

参数说明：


| 参数   | 含义     | 支持格式                    | 说明         |
| ------ | -------- | --------------------------- | ------------ |
| symbol | 概念代码 | str                         |              |
| date   | 查询日期 | str,int,float,datetime-like | 默认为前一日 |

使用样例

```python
#获取2023年3月31日的ChatGPT概念股
get_concept_stocks('309046','2023-03-31')
```
