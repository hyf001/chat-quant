# 指数成分股及权重

- ID: 300
- 分类: 指数 / 指数成分股数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/300
- 简介: 包含了常见加权指数的成分股权重

## 数据字典

| 字段 | 含义 |
| --- | --- |
| `symbol` | 股票代码 |
| `weight` | 股票所占权重（百分比） |

## 字段说明

| 字段     | 含义 |
| -------- | ---- |
| `symbol` |   股票代码   |
| `weight` |   股票所占权重（百分比）   |



## 使用代码

```get_index_weight(symbol,date)```

参数说明

| 参数   | 含义     | 详细内容                                                                                                                                                            |
| -------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| symbol | 指数代码 | 字符串格式的指数代码,例如:'000300.SH'.注意:填写['000300.SH']是错的.指数代码可查看[常用指数](https://quant.10jqka.com.cn/view/dataplatform/detail/295)|
| date   | 查询日期 | 格式：'%Y%m%d',date参数提供默认值.1.在回测模块:默认值会随着回测日期变化而变化2.在研究模块和模拟交易模块: 默认是今天的上一个交易日.                                |
