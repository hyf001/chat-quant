# 期货库存情况

- ID: 427
- 分类: 期货 / 内地期货 / 期货市场信息
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/427
- 简介: 期货库存情况表，包含库存量、库存变动、注册仓单数量、注册仓单变动、可用库存量、可用库存变动数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 品种代码 |
| date | 日期 |
| name | 仓库名称 |
| unit | 单位 |
| amount | 库存量 |
| amount\_delta | 库存变动 |
| register | 注册仓单数量 |
| register_delta | 注册仓单变动 |
| available | 可用库容量 |
| available_delta | 可用库容量变动 |

## 字段说明

* 表名：futures_inventory
* 字段名：

| 字段            | 含义           |
| --------------- | -------------- |
| symbol          | 品种代码       |
| date            | 日期           |
| name            | 仓库名称       |
| unit            | 单位           |
| amount          | 库存量         |
| amount\_delta   | 库存变动       |
| register        | 注册仓单数量   |
| register_delta  | 注册仓单变动   |
| available       | 可用库容量     |
| available_delta | 可用库容量变动 |


## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场2023年6月6日各品种库存量情况
run_query(
    query(
        futures_inventory
    ).filter(
        futures_inventory.date == '20230606',
    )
)
```
