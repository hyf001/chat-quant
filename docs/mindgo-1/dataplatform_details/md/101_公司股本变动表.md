# 公司股本变动表

- ID: 101
- 分类: 股票 / A股 / 上市公司资料
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/101
- 简介: 记录了公司股本变动情况，可根据此计算市值等数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 标的代码 |
| report\_date | 公布日 |
| change\_date | 变动日 |
| limit\_share | 限售股本 |
| limit\_share\_ashare | 限售A股 |
| limit\_share\_bshare | 限售B股 |
| limit\_share\_hshare | 限售H股 |
| negotiable\_share | 流通股本 |
| negotiable\_share\_ashare | 流通A股 |
| negotiable\_share\_bshare | 流通B股 |
| negotiable\_share\_hshare | 流通H股 |
| total\_share | 总股本 |
| total\_share\_ashare | A股总股本 |
| nontrade\_share | 非流通股本 |
