# 可转债条款信息

- ID: 224
- 分类: 债券 / 可转债 / 可转债条款信息
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/224
- 简介: 记录可转债条款数据，包含日期条款、利率条款、转股价下修条款、赎回条款、回售条款数据
