# 个股概念数据

- ID: 73
- 分类: 股票 / A股 / 同花顺概念(A股)
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/73
- 简介: A股个股概念数据表，可根据股票代码与日期查询股票所属全部概念

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 股票代码 |
| date | 日期 |
| concept | 概念名称 |

## 字段说明

**表名：concept_classification**

| 字段    | 含义     |
| ------- | -------- |
| symbol  | 股票代码 |
| date    | 日期     |
| concept | 概念名称 |



## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取同花顺300033.SZ，2023年2月1日所属概念
run_query(
    query(
        concept_classification
    ).filter(
        concept_classification.symbol == '300033.SZ',
        concept_classification.date == '20230201'
    )
)
```
