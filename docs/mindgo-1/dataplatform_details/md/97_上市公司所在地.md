# 上市公司所在地

- ID: 97
- 分类: 股票 / A股 / 上市公司资料
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/97
- 简介: 记录了A股上市公司所在的省(自治区、直辖市)、市、县(区)

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 同花顺代码 |
| report\_date | 公布日 |
| province | 省、直辖市 |
| city | 地级市 |
| county | 县、市、区 |

## 字段说明

| 字段         | 含义       |
| ------------ | ---------- |
| symbol       | 同花顺代码 |
| report\_date | 公布日     |
| province     | 省、直辖市 |
| city         | 地级市     |
| county       | 县、市、区 |
