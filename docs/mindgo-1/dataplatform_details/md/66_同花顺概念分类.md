# 同花顺概念分类

- ID: 66
- 分类: 股票 / A股 / 同花顺概念(A股)
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/66
- 简介: 同花顺概念分类数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| concept_name | 概念名称 |
| concept_symbol | 概念代码 |
| concept_code | 概念代码（同花顺） |
| concept_level | 概念分类代码 |
| concept_levelname | 概念分类名称 |
| concept_rank | 概念等级 |
| available_date | 概念可用日 |
| disabled_date | 概念删除日 |

## 字段说明

| 字段              | 含义               | 其他说明 |
| ----------------- | ------------------ | -------- |
| concept_name      | 概念名称           | 索引列   |
| concept_symbol    | 概念代码           |          |
| concept_code      | 概念代码（同花顺） |          |
| concept_level     | 概念分类代码       |          |
| concept_levelname | 概念分类名称       |          |
| concept_rank      | 概念等级           |          |
| available_date    | 概念可用日         |          |
| disabled_date     | 概念删除日         |          |


## 使用代码

```python
get_concept_relate(date='now', levels=None, fields=None)
```

参数说明：


| 参数   | 含义         | 支持格式                    | 说明                                                                     |
| ------ | ------------ | --------------------------- | ------------------------------------------------------------------------ |
| date   | 查询日期     | str,int,float,datetime-like | 默认为当前日期                                                           |
| types  | 行业分类类型 | str,list                    | 默认取所有概念，取A股概念时，`levels=['GN001001','GN001002','GN001003']` |
| fields | 字段名       | list                        | 参考“字段说明”，默认取所有可取字段                                     |

使用样例

```python
#获取2023年2月1日的A股概念信息
get_concept_relate('2023-02-01', levels=['GN001001','GN001002','GN001003'])
```
