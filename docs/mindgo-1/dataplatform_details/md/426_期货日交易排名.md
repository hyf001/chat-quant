# 期货日交易排名

- ID: 426
- 分类: 期货 / 内地期货 / 期货市场信息
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/426
- 简介: 期货日交易排名表，包含持仓龙虎榜、多头持仓龙虎榜、空头持仓龙虎榜数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| symbol | 品种代码 |
| date | 日期 |
| name | 排名类型 |
| rank | 排名 |
| member | 经纪商名字 |
| amount | 持仓数量 |
| amount_delta | 持仓数量变动 |

## 字段说明

- 表名：futures_ranking
- 字段名：


| 字段         | 含义         | 说明     |
| ------------ | ------------ | -------- |
| symbol       | 品种代码     |          |
| date         | 日期         |          |
| name         | 排名类型     |          |
| rank         | 排名         |          |
| member       | 经纪商名字   |          |
| amount       | 持仓数量     | 单位：手 |
| amount_delta | 持仓数量变动 | 单位：手 |


## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场2023年6月6日成交量龙虎榜
run_query(
    query(
        futures_ranking
    ).filter(
        futures_ranking.date == '20230606',
        futures_ranking.name == '成交量龙虎榜'
    )
)
```
