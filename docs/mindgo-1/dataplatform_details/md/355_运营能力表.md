注：

* 存货周转率，即一定期间内公司主营业务成本与平均存货的比率。公式：存货周转率TTM=最近12个月营业成本/平均存货余额TTM；平均存货余额TTM=（本期存货余额+上年同期存货余额）/2
* 应收账款周转率，即一定期间内公司的赊销收入与平均应收账款的比率。公式：应收账款周转率TTM=最近12个月营业收入/平均应收账款TTM；平均应收账款TTM=（本期应收账款+上年同期应收账款）/2
* 应付账款周转率，即应付账款的周转次数，用来反映企业应付账款的流动性和流动负债偿付能力。公式：应付账款周转率TTM=最近12个月主营业务成本/平均应付账款TTM；平均应付账款TTM=（本期应付账款+上年同期应付账款）/2
* 营运资本周转率，即公司销售收入与平均营运资本的比率。公式：营运资本周转率TTM=最近12个月营业总收入/平均营运资本；平均营运资本TTM=平均流动资产TTM-平均流动负债TTM=（上年同期流动资产-上年同期流动负债+本期流动资产-本期流动负债）/2
* 流动资产周转率，即一定期间内公司销售收入与平均流动资产的比率。公式：流动资产周转率TTM=最近12个月营业总收入/平均流动资产TTM；平均流动资产TTM=（本期流动资产+上年同期流动资产）/2
* 非流动资产周转率，即公司销售收入与平均非流动资产的比率。公式：非流动资产周转率TTM=最近12个月营业总收入/平均非流动资产TTM；平均非流动资产TTM=（本期非流动资产+上年同期非流动资产）/2
* 固定资产周转率，也称固定资产利用率，即公司营业总收入与平均固定资产的比值。公式：固定资产周转率TTM=最近12个月营业总收入/平均固定资产合计TTM；平均固定资产合计TTM=（本期固定资产合计+上年同期固定资产合计）/2
* 总资产周转率，即一定期间内公司销售收入与平均资产的比率。公式：总资产周转率TTM=最近12个月营业总收入/平均资产TTM；平均资产TTM=（本期资产总额+上年同期资产总额）/2


## 使用代码

* 调用接口

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

* 参数说明：

| 参数          | 含义                         | 支持格式                    | 说明                                                                                                                                                             |
| ------------- | ---------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query\_object | 所需要查询的表条件           | query\_object               |                                                                                                                                                                  |
| date          | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日<br />3.该参数与 `statDate`参数不能并存                   |
| statDate      | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同<br />3.该参数与 `date`不能并存 |
| latest        | 是否提取最新报告             | bool                        | 默认为 `False`,提取原始报告数据(较早日期)                                                                                                                      |

* 使用样例

```python
#获取全市场2023年2月1日全市场股票最近一期存货周转率TTM
get_fundamentals(
    query(
        ashareoperate.symbol,
        ashareoperate.report_date,
        ashareoperate.stat_date,
        ashareoperate.inventory_turnover_ttm
    ),
    date = '20230201'
)
```
