# 融资融券数据

- ID: 121
- 分类: 股票 / A股 / 市场资金数据
- 来源: https://quant.10jqka.com.cn/view/dataplatform/detail/121
- 简介: 获取A股融资融券数据

## 数据字典

| 字段 | 含义 |
| --- | --- |
| fin\_value | 融资余额(元) |
| fin\_buy\_value | 融资买入额(元) |
| fin\_refund\_value | 融资偿还额(元) |
| sec\_value | 融券余额(元) |
| sec\_sell\_value | 融券卖出额(元) |
| sec\_refund\_value | 融券偿还额(元) |
| fin\_sec\_value | 融资融券余额(元) |

## 字段说明

| 字段               | 含义             | 格式    |
| ------------------ | ---------------- | ------- |
| fin\_value         | 融资余额(元)     | float64 |
| fin\_buy\_value    | 融资买入额(元)   | float64 |
| fin\_refund\_value | 融资偿还额(元)   | float64 |
| sec\_value         | 融券余额(元)     | float64 |
| sec\_sell\_value   | 融券卖出额(元)   | float64 |
| sec\_refund\_value | 融券偿还额(元)   | float64 |
| fin\_sec\_value    | 融资融券余额(元) | float64 |


## 使用代码

```python
get_mtss(
    security_list,
    start_date=None,
    end_date='20180101',
    fields=None,
    count=None,
    is_panel=False,
)
```

参数说明：

| 参数          | 含义         | 支持格式                    | 说明                                                                 |
| ------------- | ------------ | --------------------------- | -------------------------------------------------------------------- |
| security_list | 标的代码     | str,list                    | 必须为两融标的，否则会报错                                           |
| start_date    | 起始日期     | str,int,float,datetime-like |                                                                      |
| end_date      | 结束日期     | str,int,float,datetime-like |                                                                      |
| fields        | 数据字段     | list                        | 支持字段可参考"字段说明"                                             |
| count         | 历史长度     | int                         | `count`不为0时，`start_date`必须为 `None`，否则会报错          |
| is_panel      | 返回数据格式 | bool                        | `True`:返回 `Panel`格式的数据  `False`:返回 `dict`格式的数据 |

使用样例

[IN]:

```python
# 获取平安银行, 贵州茅台2023年2月1日前3天的融资融券余额数据
value = get_mtss(
    security_list=['000001.SZ','600519.SH'],
    start_date=None,
    end_date='20230201',
    fields=['fin_value','sec_value'],
    count=3,
    is_panel=1
)
# 打印融资余额数据
print(value['fin_value'])
```

- 当`is_panel`=0时，返回 `dict`对象，其 `key`是 `symbol`即证券代码, 值是 `pandas.Dataframe`，行索引是 `datetime.datetime`对象，列索引是字段名称。
