# 阶段性交付-M5-策略资产模块

## 交付范围

本阶段基于 `docs/详细设计-M5-策略资产模块.md` 完成 M5 策略资产模块的前后端代码与测试交付。实现范围聚焦策略资产的创建、版本化、参数契约、校验状态、复制复用和策略型历史展示。

## 后端能力

- `StrategyPackage` 强类型契约：校验必填字段、entrypoint 格式、参数名、参数类型、枚举、范围和默认值一致性。
- `Strategy` 与 `StrategyVersion` 生命周期：支持创建首版、创建新版本、版本号递增、父版本追溯、当前版本切换。
- 策略元数据：支持更新名称、描述、标签、状态；元数据更新不创建新版本。
- 策略复制：支持复制摘要和复制为新策略资产，并记录复制审计。
- 校验状态：支持 `draft -> validated` 的阶段性校验结果记录，保留分项检查和执行结果引用。
- 持久化：使用标准库 SQLite 落地 `strategies`、`strategy_versions`、`strategy_copy_records` 三张表，JSON 字段按设计存储为 text。

## API 契约

- `GET /api/strategies`
- `POST /api/strategies`
- `GET /api/strategies/{strategy_id}`
- `PATCH /api/strategies/{strategy_id}`
- `POST /api/strategies/{strategy_id}/versions`
- `GET /api/strategy-versions/{version_id}`
- `POST /api/strategy-versions/{version_id}/validate`
- `POST /api/strategy-versions/{version_id}/copy`

## CLI 契约

已注册 `chatq` 命令：

```bash
uv run --project apps/api chatq strategy create --conversation-id <id> --package-file strategy_package.json
uv run --project apps/api chatq strategy version-create --strategy-id <id> --package-file strategy_package.json
uv run --project apps/api chatq strategy validate --strategy-version-id <id>
uv run --project apps/api chatq strategy get --strategy-version-id <id>
uv run --project apps/api chatq strategy copy --strategy-version-id <id> --mode summary
```

CLI 成功和失败均输出 JSON；失败包含 `error_code` 与 `message`。

## 前端能力

- 右侧对象详情展示当前策略资产、版本号、版本状态、策略类型、逻辑摘要、参数快照、entrypoint、代码产物引用和校验时间。
- 右侧对象详情支持生成示例策略、校验当前版本、复制策略摘要。
- 左侧历史区域展示策略型历史会话列表、版本标签、状态标签、策略类型和默认参数摘要。
- 前端 API client 已封装 M5 策略相关类型和调用函数。

## 集成边界

- M3 CodeArtifact 尚未实现独立服务，本阶段保存 `code_artifact_id` 引用和策略包 checksum。
- M4 smoke test 尚未实现独立运行时服务，本阶段提供 M5 侧校验状态与分项检查记录；后续 M4 暴露 smoke-test service 后，可在 `StrategyService.validate_version` 接入真实运行结果。
- M6 回测模块可读取已校验 `StrategyVersion` 的 entrypoint、参数 schema 和默认参数；正式回测运行仍属于 M6。
