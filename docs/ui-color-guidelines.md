# UI Color Guidelines

Chat-Quant 的界面以安静、克制的工作台风格为主。黑灰承担结构、层级和常规交互，绿色只用于业务强调和有效状态，红色只用于错误和危险操作。

## Foundation

- Page background: `#ffffff`
- Sidebar / weak surface: `#fafafa`
- Primary text: `#18181b`
- Body text: `#3f3f46`
- Secondary text: `#52525b`
- Muted text: `#71717a`
- Placeholder text: `#a1a1aa`
- Default border: `#e4e4e7`
- Strong border / input border: `#d4d4d8`

## Buttons

- Primary button: `#18181b` background, `#ffffff` text.
- Primary hover: `#000000`.
- Disabled button: `#d4d4d8` background, `#71717a` text.
- Icon button: transparent background, `#71717a` icon.
- Icon button hover: `#e4e4e7` background, `#18181b` icon.

## Selection

- Current main session: `#18181b` background, `#ffffff` text.
- Menu selection: no filled background; use a leading check mark in `#18181b`.
- Current project card: `#fafafa` background, `#18181b` border, green check status.

## Feedback

- Success / valid: `#059669` text, `#ecfdf5` background, `#a7f3d0` border.
- Warning: `#d97706` text, `#fffbeb` background, `#fde68a` border.
- Error / danger: `#dc2626` text, `#fef2f2` background, `#fecaca` border.

## Usage Rules

- Do not use blue as a default action color.
- Use gray hover for ordinary lists, menus, cards, and icon buttons.
- Use red only for failed states, errors, and destructive actions.
- Keep green low frequency: current/valid/success, charts, and positive metrics.
