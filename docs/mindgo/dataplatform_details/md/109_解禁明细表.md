# 解禁明细表

- ID: 109
- 分类: 股票 / A股 / 上市公司资料
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/109
- 简介: 记录A股上市公司限售股解禁明细数据

## 字段说明

| 字段                | 含义             |
| ------------------- | ---------------- |
| symbol              | 股票代码         |
| report\_date        | 公布日           |
| unlimited\_date     | 可流通日期       |
| limit\_date         | 限售开始日期     |
| unlimited\_num      | 本期流通数量     |
| negotiable\_num     | 已流通数量       |
| unlimited\_num\_pub | 本期公布流通数量 |
| limited\_num        | 待流通数量       |
| limited\_reasom     | 流通股份类型     |
| holding\_cost       | 持股成本         |
