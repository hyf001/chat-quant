# 业绩快报

- ID: 343
- 分类: 股票 / A股 / 上市公司财务数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/343
- 简介: A股上市公司业绩快报数据

## 字段说明

**表名：profit_report**

| 含义                       | 字段                      |
| -------------------------- | ------------------------- |
| 股票代码                   | symbol                    |
| 公布日                     | report_date               |
| 报告期                     | stat_date                 |
| 主营业务收入               | income_from_main_business |
| 主营业务利润               | profit_of_main_business   |
| 利润总额                   | total_profit              |
| 归属母公司股东的净利润     | parent_net_profit         |
| 摊薄每股收益EPS            | diluted_eps               |
| 基本每股收益EPS            | basic_eps                 |
| 全面摊薄净资产收益率ROE    | diluted_roe               |
| 加权净资产收益率ROE        | weighted_roe              |
| 总资产                     | asset                     |
| 净资产                     | net_asset                 |
| 业绩快报简要说明           | brief_report              |
| 归属母公司股东的扣非净利润 | parent_net_profit_excl    |

## 使用代码

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

<br>

参数说明：

| 参数         | 含义                         | 支持格式                    | 说明                                                                                                                                                             |
| ------------ | ---------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query_object | 所需要查询的表条件           | query_object                |                                                                                                                                                                  |
| date         | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日<br />3.该参数与 `statDate`参数不能并存                   |
| statDate     | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同<br />3.该参数与 `date`不能并存 |
| latest       | 是否提取最新报告             | bool                        | 默认为 `False`,提取原始报告数据(较早日期)                                                                                                                      |

<br>

使用样例

```python
#获取全市场2022年报业绩快报中的归母扣非净利润数据
get_fundamentals(
    query(
        profit_report.symbol,
        profit_report.date,
        profit_report.report_date,
        profit_report.stat_date,
        profit_report.parent_net_profit_excl
    ),
    statDate = '2022q4'
)
```
