# 定向增发事件

- ID: 396
- 分类: 股票 / A股 / 另类数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/396
- 简介: 记录了A股上市公司定向增发事件相关数据

## 字段说明

- 表名：private\_placement
- 字段名
  | 字段             | 含义         |
| ---------------- | ------------ |
| plan\_date | 增发预案日 |
| rate | 增发进度 |
| plan\_low\_price | 增发预案发行价格下限 |
| plan\_high\_price | 增发预案发行价格上限 |
| quantity | 增发预案募集数量 |
| amount | 增发预案募集金额 |
| stock\_buying\_pattern | 增发认购方式 |
