# 可转债余额变动表

- ID: 229
- 分类: 债券 / 可转债 / 可转债条款信息
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/229
- 简介: 记录可转债余额变动情况以及变动原因

## 字段说明

| 字段           | 含义       |
| -------------- | ---------- |
| symbol         | 可转债代码 |
| change\_date   | 变更日     |
| remaining      | 可转债余额 |
| change\_reason | 变动原因   |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场可转债余额变动表
run_query(
    query(
        cbond_remaining_change
    )
)
```
