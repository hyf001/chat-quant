## 使用代码

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

参数说明：


| 参数         | 含义                         | 支持格式                    | 说明                                                                                                                                                           |
| ------------ | ---------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query_object | 所需要查询的表条件           | query_object                |                                                                                                                                                                |
| date         | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日<br />3.该参数与 `statDate`参数不能并存                   |
| statDate     | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同<br />3.该参数与 `date`不能并存 |
| latest       | 是否提取最新报告             | bool                        | 默认为`False`,提取原始报告数据(较早日期)                                                                                                                       |

<br>

使用样例

```python
#获取全市场2022年报现金流量表中的经营活动产生的现金流量净额数据，仅取合并报表
get_fundamentals(
    query(
        cashflow.symbol,
        cashflow.report_date,
        cashflow.stat_date,
        cashflow.sub_total_of_cos_from_oa
    ).filter(
        cashflow.reporttypecode == 'HB'
    ),
    statDate = '2022q4'
)
```

```python
#获取全市场2023年2月1日全市场股票最近一期现金流量表中的经营活动产生的现金流量数据，取最新报告数据
get_fundamentals(
    query(
        cashflow.symbol,
        cashflow.date,
        cashflow.report_date,
        cashflow.stat_date,
        cashflow.sub_total_of_cos_from_oa
    ),
    date = '20230201',
    latest = True
)
```
