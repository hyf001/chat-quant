# 期货分钟行情数据

- ID: 422
- 分类: 期货 / 内地期货 / 期货行情数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/422
- 简介: 记录了内地交易所期货分钟频行情数据

## 字段说明

| 字段          | 含义         | 格式    | 其他说明 |
| ------------- | ------------ | ------- | -------- |
| open          | 开盘价       | float64 |          |
| high          | 最高价       | float64 |          |
| low           | 最低价       | float64 |          |
| close         | 收盘价       | float64 |          |
| volume        | 成交量       | float64 |          |
| turnover      | 成交金额(元) | float64 |          |
| open_interest | 持仓         | float64 |          |

## 使用代码

```python
get_price_future(
    symbol_list,
    start_date,
    end_date,
    fre_step,
    fields=None,
    skip_paused=False,
    fq=None,
    bar_count=0,
    is_panel=0,
)
```

参数说明：

| 参数        | 含义             | 支持格式                    | 说明                                                                         |
| ----------- | ---------------- | --------------------------- | ---------------------------------------------------------------------------- |
| symbol_list | 标的类型         | str,list                    |                                                                              |
| start_date  | 起始日期         | str,int,float,datetime-like |                                                                              |
| end_date    | 结束日期         | str,int,float,datetime-like |                                                                              |
| fre_step    | 时间步长         | str                         | 取分钟行情时 `fre_step='1m'`                                               |
| fields      | 数据字段         | list                        | 支持字段可参考“字段说明”                                                   |
| skip_paused | 是否跳过停牌数据 | bool                        | `True`:表示跳过 <br />`False`:表示不跳过                                 |
| fq          | 复权选项         | str                         | `fq=None`: 不复权 <br /> `fq='post'`: 后复权 <br /> `fq='pre'`: 前复权 |
| bar_count   | 历史长度         | int                         | `bar_count`不为0时 `start_date`必须为 `None`，否则会报错               |
| is_panel    | 返回数据格式     | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据   |

使用样例

```python
# 获取IC2304、IF2304两个标的在2023年4月6日10点30分前3分钟的数据
value = get_price_future(
    symbol_list = ['IC2304','IF2304'],
    start_date = None,
    end_date = '20230406 10:30',
    fre_step = '1m',
    fields=['close', 'high', 'low'],
    bar_count = 3,
    is_panel = 1
)
# 打印收盘价数据
print(value['close']) 
```
