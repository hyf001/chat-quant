# 期货日频行情数据

- ID: 174
- 分类: 期货 / 内地期货 / 期货行情数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/174
- 简介: 期货日频行情数据

## 字段说明

| 字段          | 含义         | 格式    | 其他说明                       |
| ------------- | ------------ | ------- | ------------------------------ |
| open          | 开盘价       | float64 |                                |
| high          | 最高价       | float64 |                                |
| low           | 最低价       | float64 |                                |
| close         | 收盘价       | float64 |                                |
| volume        | 成交量       | float64 |                                |
| turnover      | 成交金额(元) | float64 |                                |
| open_interest | 持仓         | float64 |                                |
| high_limit    | 涨停价(元)   | float64 |                                |
| low_limit     | 跌停价(元)   | float64 |                                |
| settle        | 结算价(元)   | float64 |                                |
| change        | 涨跌(元)     | float64 |                                |
| quote_rate    | 涨跌幅(%)    | float64 |                                |
| amp_rate      | 振幅(%)      | float64 | 振幅=(最高价－最低价)/昨收盘价 |
| pos_change    | 仓差         | float64 |                                |

## 使用代码

```python
get_price_future(
    symbol_list,
    start_date,
    end_date,
    fre_step,
    fields=None,
    skip_paused=False,
    fq=None,
    bar_count=0,
    is_panel=0,
)
```

参数说明：

| 参数        | 含义             | 支持格式                    | 说明                                                                         |
| ----------- | ---------------- | --------------------------- | ---------------------------------------------------------------------------- |
| symbol_list | 标的类型         | str,list                    |                                                                              |
| start_date  | 起始日期         | str,int,float,datetime-like |                                                                              |
| end_date    | 结束日期         | str,int,float,datetime-like |                                                                              |
| fre_step    | 时间步长         | str                         | 取日频行情时 `fre_step='1d'`                                               |
| fields      | 数据字段         | list                        | 支持字段可参考“字段说明”                                                   |
| skip_paused | 是否跳过停牌数据 | bool                        | `True`:表示跳过 <br />`False`:表示不跳过                                 |
| fq          | 复权选项         | str                         | `fq=None`: 不复权 <br /> `fq='post'`: 后复权 <br /> `fq='pre'`: 前复权 |
| bar_count   | 历史长度         | int                         | `bar_count`不为0时 `start_date`必须为 `None`，否则会报错               |
| is_panel    | 返回数据格式     | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据   |

使用样例

```python
[IN]:
# 获取IC2304、IF2304两个标的在2023年4月6日前3天的数据
value = get_price_future(
    symbol_list = ['IC2304','IF2304'],
    start_date = None,
    end_date = '20230406',
    fre_step = '1d',
    fields=['close', 'high', 'low'],
    bar_count = 3,
    is_panel = 1
)
# 打印收盘价数据
print(value['close']) 
```

```python
[OUT]:
            IC2304  IF2304
2023-04-03  6406.0  4091.2
2023-04-04  6415.0  4111.8
2023-04-06  6411.4  4098.0
```

## 数据样例

- 当 `symbol_list`传入字符串时，返回 `pandas.Dataframe`对象，，行索引是 `datetime.datetime`对象，列索引是字段名称。


|            | open   | high   | low    | close  | volume  |
| ---------- | ------ | ------ | ------ | ------ | ------- |
| 2023-04-03 | 6357.2 | 6429.6 | 6353.0 | 6406.0 | 38583.0 |
| 2023-04-04 | 6412.0 | 6417.2 | 6382.2 | 6415.0 | 33237.0 |
| 2023-04-06 | 6400.0 | 6427.2 | 6391.0 | 6411.4 | 32892.0 |

- 当 `symbol_list`传入列表时，且 `is_panel`=0时，返回 `dict`对象，其 `key`是 `symbol`即证券代码, 值是 `pandas.Dataframe`，行索引是 `datetime.datetime`对象，列索引是字段名称。
