# 基金十大持仓

- ID: 277
- 分类: 基金 / 场外基金 / 基金持仓情况
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/277
- 简介: 基金季报披露的十大持仓数据

## 字段说明

| 字段                | 含义           | 格式     |
| ------------------- | -------------- | -------- |
| symbol              | 基金代码       | str      |
| position\_symbol    | 持仓代码       | str      |
| name                | 持仓名称       | str      |
| type                | 类型           | str      |
| amount              | 数量           | float64  |
| value               | 市值           | float64  |
| change              | 持仓变动       | float64  |
| value\_percent      | 证券投资市值比 | float64  |
| net\_value\_percent | 基金资产净值比 | float64  |
| report\_date        | 公告日期       | datetime |
| stat\_date          | 报告截止日期   | datetime |

run_query(query_object)
