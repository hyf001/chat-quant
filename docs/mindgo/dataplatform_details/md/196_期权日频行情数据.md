# 期权日频行情数据

- ID: 196
- 分类: 期权 / 金融期权 / 期权行情数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/196
- 简介: 沪深交易所ETF期权日频行情数据

## 字段说明

| 字段   | 含义   | 格式    | 其他说明 |
| ------ | ------ | ------- | -------- |
| open   | 开盘价 | float64 |          |
| high   | 最高价 | float64 |          |
| low    | 最低价 | float64 |          |
| close  | 收盘价 | float64 |          |
| volume | 成交量 | float64 |          |

## 使用代码

```python
get_price(
    securities,
    start_date=None,
    end_date='20180101',
    fre_step='1d',
    fields=None,
    bar_count=0,
    is_panel=False,
)
```

参数说明：

| 参数       | 含义         | 支持格式                    | 说明                                                                       |
| ---------- | ------------ | --------------------------- | -------------------------------------------------------------------------- |
| securities | 标的类型     | str,list                    |                                                                            |
| start_date | 起始日期     | str,int,float,datetime-like |                                                                            |
| end_date   | 结束日期     | str,int,float,datetime-like |                                                                            |
| fre_step   | 时间步长     | str                         | 取日频行情时 `fre_step='1d'`                                             |
| fields     | 数据字段     | list                        | 支持字段可参考“字段说明”                                                 |
| bar_count  | 历史长度     | int                         | `bar_count`不为0时，`start_date`必须为 `None`，否则会报错            |
| is_panel   | 返回数据格式 | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据 |

使用样例

```python
[IN]:
# 获取中证500ETF认购期权2023年5月6500, 中证500ETF认购期权2023年5月6750两个标的2023年4月6日前3天的数据
value = get_price(
    securities = ['90002069.SZ','90002070.SZ'],
    start_date=None,
    end_date='20230406',
    fre_step='1d',
    fields=['open','high','low','close','volume'],
    bar_count=3,
    is_panel=1,
)
# 打印收盘价数据
print(value['close']) 
```

## 数据样例
