# 机构调研数据

- ID: 397
- 分类: 股票 / A股 / 另类数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/397
- 简介: 记录A股上市公司机构调研事件相关数据

## 字段说明

* 表名：company\_research
* 字段名：
  | 字段             | 含义         |
| ---------------- | ------------ |
| symbol | 同花顺代码 |
| declare\_date | 调研公告日期 |
| investigation\_date | 调研时间 |
| institutions\_cnt | 调研机构家数 |
| institutions | 调研机构名称 |
| investigation\_type | 调研类型 |
| investigation\_place | 调研地点 |
| pe\_cnt | 调研私募家数 |
| pe | 调研私募名称 |
| fund\_cnt | 调研基金家数 |
| fund | 调研基金名称 |
| security\_cnt | 调研券商家数 |
| security | 调研券商名称 |
| insurance\_cnt | 调研保险家数 |
| insurance | 调研保险名称 |
| qfii\_cnt | 调研qfii家数 |
| qfii | 调研qfii名称 |
| overseas\_cnt | 调研海外机构家数 |
| overseas | 调研海外机构名称 |
| others\_cnt | 调研其他类别家数 |
| others | 调研其他类别名称 |

## 使用代码

```python
run_query(query(query_object))

```

使用样例

```python
#获取全市场上市公司历史机构调研情况数据
run_query(
    query(
        company_research
    )
)
```
