# 场内基金基本信息

- ID: 249
- 分类: 基金 / 场内基金 / 基金基本信息
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/249
- 简介: 场内基金(ETF、LOF等)基本信息，包括代码、简称、上市日期、退市日期等数据

## 字段说明

| 字段         | 含义     | 其他说明               |
| ------------ | -------- | ---------------------- |
| symbol       | 标的代码 | 索引列                 |
| display_name | 中文简称 |                        |
| name         | 拼音简称 |                        |
| start_date   | 上市日期 |                        |
| end_date     | 退市日期 | 如未退市则为2200-01-01 |
| type         | 种类     |                        |
| exchange     | 交易所   |                        |

## 使用代码

```python
get_all_securities(ty=None,date=None)
```

参数说明：

| 参数 | 含义     | 支持格式                    | 说明                                                                                                                 |
| ---- | -------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| ty   | 标的类型 | str                         | 支持类型见下表                                                                                                       |
| date | 查询日期 | str,int,float,datetime-like | 1.在回测环境:默认值会随着回测日期变化而变化,的上一个交易日<br />2.在研究环境和模拟交易环境: 默认是今天的上一个交易日 |

| ty参数 | 含义             | 说明                                            |
| ------ | ---------------- | ----------------------------------------------- |
| etf    | 交易所交易基金   | 后缀同时支持.OF与.SZ/.SH两种形式,使用时注意去重 |
| lof    | 上市型开放式基金 | 后缀同时支持.OF与.SZ/.SH两种形式,使用时注意去重 |
| qdii   | QDII基金         | 后缀同时支持.OF与.SZ/.SH两种形式,使用时注意去重 |
| fja    | 分级A            | 后缀同时支持.OF与.SZ/.SH两种形式,使用时注意去重 |
| fjb    | 分级B            | 后缀同时支持.OF与.SZ/.SH两种形式,使用时注意去重 |
| fund   | 封闭式基金&REIT  |                                                 |

使用样例

```python
#获取2023年2月1日处于上市状态的所有ETF基金的基本信息
get_all_securities('etf','2023-02-01')
```

```python
#获取当前处于上市状态的所有LOF基金的基本信息
get_all_securities('lof','now')
```
