## 字段说明

**表名：profit_forecast**


| 含义                   | 字段                         | 说明                                                             |
| ---------------------- | ---------------------------- | ---------------------------------------------------------------- |
| 股票代码               | symbol                       |                                                                  |
| 报告期                 | stat_date                    |                                                                  |
| 报告公布日             | report_date                  |                                                                  |
| 业绩预告类型           | profit_type                  |                                                                  |
| 预告净利润变动         | np_change_range              | 单位：%；取np_change_lower与 np_change_upper之中绝对值最大的一个 |
| 预告净利润变动下限     | np_change_lower              | 单位：%                                                          |
| 预告净利润变动上限     | np_change_upper              | 单位：%                                                          |
| 预告净利润下限         | np_lower                     | 单位：万元                                                       |
| 预告净利润上限         | np_upper                     | 单位：万元                                                       |
| 预告eps上限            | eps_upper                    | 单位：元                                                         |
| 预告eps下限            | eps_lower                    | 单位：元                                                         |
| 预告eps变动上限        | eps_change_upper             | 单位：%                                                          |
| 预告eps变动下限        | eps_change_lower             | 单位：%                                                          |
| 预告扣除后营业收入上限 | operating_income_excl_upper  | 单位：万元                                                       |
| 预告扣除后营业收入上限 | operating_income_excl_lower  | 单位：万元                                                       |
| 预告扣非净利润上限     | np_excl_upper                | 单位：万元                                                       |
| 预告扣非净利润下限     | np_excl_lower                | 单位：万元                                                       |
| 预告扣非净利润变动上限 | np_excl_change_upper         | 单位：%                                                          |
| 预告扣非净利润变动下限 | np_excl_change_lower         | 单位：%                                                          |
| 预告营业收入上限       | operating_income_upper_limit | 单位：万元                                                       |
| 预告营业收入下限       | operating_income_lower_limit | 单位：万元                                                       |

## 使用代码

```python
get_fundamentals(query_object, date=None, statDate=None, latest=False)
```

<br>

参数说明：

| 参数         | 含义                         | 支持格式                    | 说明                                                                                                                                                                |
| ------------ | ---------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query_object | 所需要查询的表条件           | query_object                |                                                                                                                                                                     |
| date         | 查询指定日期的财务数据       | str,int,float,datetime-like | 1.在回测模块:默认值会随着回测日期变化而变化<br />2.在研究模块和模拟交易模块: 默认是今天的上一个交易日 <br />  3.该参数与 `statDate`参数不能并存                   |
| statDate     | 查询指定季度或年份的财务数据 | str                         | 1.季报：'年+q+季度序号'，例如：'2022q1'表示2022年一季报<br />2.年报：年份的数字，例如：'2022'表示2022年年报，效果与'2022q4'相同 <br />  3.该参数与 `date`不能并存 |
| latest       | 是否提取最新报告             | bool                        | 默认为 `False`,提取原始报告数据(较早日期)                                                                                                                         |

<br>

使用样例

```python
#获取全市场2022年报业绩预告中的扣非净利润上限与下限
get_fundamentals(
    query(
        profit_forecast.symbol,
        profit_forecast.report_date,
        profit_forecast.stat_date,
        profit_forecast.np_excl_upper,
        profit_forecast.np_excl_lower 
    ),
    statDate = '2022q4'
)
```
