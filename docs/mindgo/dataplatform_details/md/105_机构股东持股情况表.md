# 机构股东持股情况表

- ID: 105
- 分类: 股票 / A股 / 上市公司资料
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/105
- 简介: 记录了A股上市公司机构股东持股数据

## 字段说明

| 字段              | 含义          |
| ----------------- | ------------- |
| symbol            | 股票代码      |
| report\_date      | 公布日        |
| end\_date         | 截止日期      |
| institution\_name | 机构/基金名称 |
| institution\_id   | 机构/基金id   |
| institution\_type | 机构类型      |
| holding\_num      | 持股数量      |
| holding\_size     | 持股市值      |
| holding\_ratio    | 占流通股比例  |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场公司机构股东持股情况表
run_query(
    query(
        institution_holding
    ).filter(
        institution_holding.symbol =='300033.SZ'
    )
)
```
