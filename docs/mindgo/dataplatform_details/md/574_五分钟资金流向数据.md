# 五分钟资金流向数据

- ID: 574
- 分类: 股票 / A股 / 市场资金数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/574
- 简介: 记录了五分钟级别主动买入、大单特大单等资金流向数据

## 字段说明

| 含义                     | 字段          | 格式    |
| ------------------------ | ------------- | ------- |
| 主动买入特大单金额（元） | act_buy_xl    | float64 |
| 被动买入特大单金额（元） | pas_buy_xl    | float64 |
| 主动买入大单金额（元）   | act_buy_l     | float64 |
| 被动买入大单金额（元）   | pas_buy_l     | float64 |
| 主动买入中单金额（元）   | act_buy_m     | float64 |
| 被动买入中单金额（元）   | pas_buy_m     | float64 |
| 主动卖出特大单金额（元） | act_sell_xl   | float64 |
| 被动卖出特大单金额（元） | pas_sell_xl   | float64 |
| 主动卖出大单金额（元）   | act_sell_l    | float64 |
| 被动卖出大单金额（元）   | pas_sell_l    | float64 |
| 主动卖出中单金额（元）   | act_sell_m    | float64 |
| 被动卖出中单金额（元）   | pas_sell_m    | float64 |

| 小单卖出金额（元）       | sell_l        | float64 |

| 大单净量                 | l_net_value   | float64 |

说明：

大单判断方法

成交量判断
小单：成交量<10000
中单：10000<成交量<60000
大单：60000<成交量<200000
特大单：成交量>200000
成交金额判断
小单：成交金额<50000
中单：50000<成交金额<300000
大单：300000<成交金额<1000000
特大单：成交金额>1000000

主被动判断方法
1．主动大单

逐笔成交中，委托序号较大方为主动方，委托序号较大方的连续单即为主动单。
主动买单：委买序号>委卖序号，委买序号相同
主动卖单：委买序号<委卖序号，委卖序号相同
2．被动大单

同一价位，委托序号较小方为被动方，委托序号较小方的成交单累计即为被动单。
被动大单可能不在逐笔成交中连续出现，会被不同价位隔断。
被动买单：价格相同，委买序号<委卖序号，委买序号相同
被动卖单：价格相同，委买序号>委卖序号，委卖序号相同

被动买入小单量 = 主动卖出特大单量+主动卖出大单量+主动卖出中单量+主动卖出小单量-被动买入特大单量-被动买入大单量-被动买入中单量

被动卖出小单量 = 主动买入特大单量+主动买入大单量+主动买入中单量+主动买入小单量-被动卖出特大单量-被动卖出大单量-被动卖出中单量

## 使用代码

```python
get_money_flow_step(
    security_list,
    start_date=None,
    end_date='20180101',
    fre_step='1d',
    fields=None,
    count=None,
    is_panel=False,
)
```

参数说明：

| 参数          | 含义         | 支持格式                    | 说明                                                                      |
| ------------- | ------------ | --------------------------- | ------------------------------------------------------------------------- |
| security_list | 标的代码     | str,list                    |                                                                           |
| start_date    | 起始日期     | str,int,float,datetime-like |                                                                           |
| end_date      | 结束日期     | str,int,float,datetime-like |                                                                           |
| fre_step      | 时间步长     | str                         | 取5分钟频资金数据时 `fre_step='5m'`                                     |
| fields        | 数据字段     | list                        | 支持字段可参考"字段说明"                                                  |
| count         | 历史长度     | int                         | `count`不为0时，`start_date`必须为 `None`，否则会报错               |
| is_panel      | 返回数据格式 | bool                        | `True`:返回 `Panel`格式的数据<br /> `False`:返回 `dict`格式的数据 |

使用样例

```python
[IN]:
# 获取平安银行, 贵州茅台2023年2月1日10点30分前3个5分钟bar的特大单买入数据
value = get_money_flow_step(
    security_list=['000001.SZ','600519.SH'],
    start_date=None,
    end_date='20230201 10:30',
    fre_step='5m',
    fields=['act_buy_xl','pas_buy_xl'],
    count=3,
    is_panel=1
)
# 打印主动买入特大单金额数据
print(value['act_buy_xl'])
```
