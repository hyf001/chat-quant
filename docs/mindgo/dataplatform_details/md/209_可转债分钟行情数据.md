# 可转债分钟行情数据

- ID: 209
- 分类: 债券 / 可转债 / 可转债行情
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/209
- 简介: 沪深交易所上市可转债分钟行情数据

## 字段说明

| 字段      | 含义         | 格式    | 其他说明                           |
| --------- | ------------ | ------- | ---------------------------------- |
| open      | 开盘价       | float64 |                                    |
| high      | 最高价       | float64 |                                    |
| low       | 最低价       | float64 |                                    |
| close     | 收盘价       | float64 |                                    |
| factor    | 复权因子     | float64 | 复权因子 = 后复权价格 / 不复权价格 |
| volume    | 成交量       | float64 |                                    |
| turnover  | 成交金额(元) | float64 |                                    |
| is_paused | 是否停牌     | float64 | 返回值为0或1, 0表示未停牌          |

## 使用代码

```python
get_price(
    securities,
    start_date=None,
    end_date='20180101',
    fre_step='1d',
    fields=None,
    skip_paused=False,
    fq='pre',
    bar_count=0,
    is_panel=False,
)
```

参数说明：


| 参数        | 含义             | 支持格式                    | 说明                                                                   |
| ----------- | ---------------- | --------------------------- | ---------------------------------------------------------------------- |
| securities  | 标的类型         | str,list                    |                                                                        |
| start_date  | 起始日期         | str,int,float,datetime-like |                                                                        |
| end_date    | 结束日期         | str,int,float,datetime-like |                                                                        |
| fre_step    | 时间步长         | str                         | 取1分钟行情时`fre_step='1m'`                                           |
| fields      | 数据字段         | list                        | 支持字段可参考“字段说明”                                             |
| skip_paused | 是否跳过停牌数据 | bool                        | `True`:表示跳过 <br />`False`:表示不跳过                               |
| fq          | 复权选项         | str                         | `fq=None`: 不复权 <br /> `fq='post'`: 后复权 <br /> `fq='pre'`: 前复权 |
| bar_count   | 历史长度         | int                         | `bar_count`不为0时，`start_date`必须为 `None`，否则会报错              |
| is_panel    | 返回数据格式     | bool                        | `True`:返回 `Panel`格式的数据 <br /> `False`:返回 `dict`格式的数据     |

使用样例

```python
[IN]:
# 获取溢利转债, 联泰转债2023年2月1日10点59分前3分钟的数据
value = get_price(['123018.SZ','113526.SH'], None, '20230201 10:59', '1m', ['close', 'high', 'low'], True, None, 3, is_panel=1)
# 打印收盘价数据
print(value['close']) 
```

```python
[OUT]:

2023-02-01 10:58:00     273.78     129.80
```

## 数据样例

- 当 `securities`传入字符串时，返回 `pandas.Dataframe`对象，，行索引是 `datetime.datetime`对象，列索引是字段名称。

| ------------------- | ------ | ------ | ------ | ------ | ------ |
| 2023-02-01 10:54:00 | 272.90 | 272.90 | 272.62 | 272.85 | 2440.0 |
| 2023-02-01 10:55:00 | 272.97 | 273.58 | 272.83 | 273.58 | 3790.0 |
| 2023-02-01 10:56:00 | 273.22 | 273.50 | 273.22 | 273.32 | 2790.0 |

- 当 `securities`传入列表时，且 `is_panel`=0时，返回 `dict`对象，其 `key`是 `symbol`即证券代码, 值是 `pandas.Dataframe`，行索引是 `datetime.datetime`对象，列索引是字段名称。
