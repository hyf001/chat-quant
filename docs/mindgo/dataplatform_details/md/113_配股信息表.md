# 配股信息表

- ID: 113
- 分类: 股票 / A股 / 上市公司资料
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/113
- 简介: 记录上市公司配股信息

## 字段说明

| 字段           | 含义           |
| -------------- | -------------- |
| symbol         | 股票代码       |
| date_of_record | 配股股权登记日 |
| number         | 每股配股数     |
