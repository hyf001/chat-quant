# 新闻评级数据

- ID: 393
- 分类: 股票 / A股 / 另类数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/393
- 简介: 记录了新闻标题、新闻来源、新闻评级、新闻发布时间、新闻评级时间、对应股票代码数据

## 字段说明

- 表名：asharenews
- 字段名：


  | 含义         | 字段   | 说明                                                                   |
  | ------------ | ------ | ---------------------------------------------------------------------- |
  | 股票代码     | symbol |                                                                        |
  | 新闻发布时间 | ctime  |                                                                        |
  | 审核评级时间 | rtime  |                                                                        |
  | 文章标题     | title  |                                                                        |
  | 文章来源     | source |                                                                        |
  | 新闻评级     | nature | 字符串形式：<br />'0':未标记<br />'1':利好<br />'2':利空<br />'3':中性 |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场最近1000条利好新闻
run_query(
    query(
        asharenews
    ).filter(
        asharenews.nature == '1'
    ).order_by(
        asharenews.ctime.desc()
    ).limit(1000)
)
```
