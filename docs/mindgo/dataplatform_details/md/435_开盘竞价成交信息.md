# 开盘竞价成交信息

- ID: 435
- 分类: 股票 / A股 / 行情数据(A股)
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/435
- 简介: 记录A股开盘集合竞价成交信息数据

## 字段说明

| 字段     | 含义     | 格式    |
| -------- | -------- | ------- |
| price    | 成交价   | float64 |
| turnover | 成交金额 | float64 |

## 使用代码

```python
get_call_auction(symbol, dt=None)
```

参数说明：


| 参数   | 含义     | 支持格式                    | 说明                 |
| ------ | -------- | --------------------------- | -------------------- |
| symbol | 时间步长 | str,list                    |                      |
| dt     | 日期     | str,int,float,datetime-like | 不传默认取最新交易日 |

使用样例

```python
[IN]:
get_call_auction(['000001.SZ'],'20230613')

```

```python
[OUT]:
           price   turnover
symbol                 
000001.SZ  11.76  3988992.0
```
