# 举牌事件

- ID: 394
- 分类: 股票 / A股 / 另类数据
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/394
- 简介: 记录了A股上市公司举牌事件数据

## 字段说明

* 表名：banner\_acquisition
* 字段名
  | 字段                         | 含义                 |
| ---------------------------- | -------------------- |
| symbol | 股票代码 |
| report\_date | 举牌公告日期 |
| name | 举牌方 |
| start\_date | 举牌起始日期 |
| end\_date | 举牌截止日期 |
| add\_quantity | 本次举牌增持数量 |
| add\_quantity\_ratio | 本次举牌增持数量占总股本比例 |

## 使用代码

```python
run_query(query(query_object))
```

使用样例

```python
#获取全市场历史举牌数据
run_query(
    query(
        banner_acquisition
    )
)
```
