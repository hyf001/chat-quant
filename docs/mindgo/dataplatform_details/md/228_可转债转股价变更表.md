# 可转债转股价变更表

- ID: 228
- 分类: 债券 / 可转债 / 可转债条款信息
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/228
- 简介: 记录可转债历史转股价变更信息

## 字段说明

| 字段               | 含义       |
| ------------------ | ---------- |
| symbol             | 可转债代码 |
| report\_date       | 公布日     |
| change\_date       | 实际变更日 |
| conversion\_price  | 转股价     |
| conversion\_reason | 变更原因   |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场可转债转股价变更表
run_query(
    query(
        cbond_conversion_change
    )
)
```
