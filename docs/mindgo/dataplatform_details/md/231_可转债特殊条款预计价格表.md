# 可转债特殊条款预计价格表

- ID: 231
- 分类: 债券 / 可转债 / 可转债条款信息
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/231
- 简介: 可转债特殊条款预计执行价格数据

## 字段说明

| 字段         | 含义       |
| ------------ | ---------- |
| symbol       | 同花顺代码 |
| change\_date | 预计变更日 |
| term\_type   | 条款类型   |
| term\_price  | 条款价格   |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场可转债特殊条款预计价格表
run_query(
    query(
        cbond_term_price
    )
)
```
