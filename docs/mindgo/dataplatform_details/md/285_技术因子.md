## 使用代码

```python

```

参数说明：

| 参数         | 含义      | 说明                     |

| query_object | query对象 | 可参考[query对象使用说明]() |

使用样例

```python
#获取2023年2月1日全市场股票的因子数据
run_query(
    query(
        factor
    ).filter(
        factor.date == '2023-02-01'
    )
)
```
