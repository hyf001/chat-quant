# 公司更名信息

- ID: 81
- 分类: 股票 / A股 / 上市公司资料
- URL: https://quant.10jqka.com.cn/view/dataplatform/detail/81
- 简介: 记录A股上市公司简称变更情况，可用来判断ST、退市情况

## 字段说明

| 字段             | 含义             |
| ---------------- | ---------------- |
| symbol           | 同花顺代码       |
| report_date      | 公布日           |
| change_date      | 截至日           |
| stock_name       | 证券简称         |
| original_name    | 原证券简称       |
| stock_name_en    | 证券简称(英文)   |
| original_name_en | 原证券简称(英文) |

## 使用代码

```python
run_query(query_object)
```

使用样例

```python
#获取全市场公司更名信息表
run_query(
    query(
        name_change

)
```
