# 本地SDK

## 一、前言

为了确保产品的最佳使用效果和您的成功应用，我们设定了以下申请条件。

## 二、申请条件

1、投资机构，需具备至少2年的量化策略研发经验。

2、您的团队需要至少拥有3个开发人员，并且其中至少有一名具有6年以上Python开发经验的资深开发人员。

## 三、申请流程

1、如果您满足上述条件，请将您的**机构简介**、**开发团队介绍**、**产品预期的使用场景**以及**同花顺账号**发送至我们的邮箱SuperMind@myhexin.com

2、我们的工作人员将在收到邮件后的5个工作日内进行审核，并与您联系进一步的沟通事宜。
审核通过后，我们将为您的团队提供产品使用的相关培训和技术支持。

## 四、注意事项

1、请确保您提供的信息真实完整，所需要信息请参照**三、申请流程**，否则可能导致您的申请被拒绝

2、本产品仅供符合条件的机构使用，未经许可不得转让或转售。

3、使用过程中如遇到任何问题，欢迎随时联系我们获取帮助。

感谢您对我们产品的关注和支持，我们期待与您的合作，共同开启新的机遇！
