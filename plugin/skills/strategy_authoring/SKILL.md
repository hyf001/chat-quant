# Strategy Authoring

Use this skill when the user wants to create, refine, or reason about a trading strategy.

Make assumptions explicit, define entry and exit rules clearly, and keep strategy parameters inspectable. When code is produced, favor readable, testable Python and preserve user intent over overfitting.
